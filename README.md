# Milenion Collection

Aplicativo independente para gerenciar coleção de cartas, decks, wishlist, objetivos e compras.

## Tecnologias

- React
- Vite
- Supabase Auth
- Supabase PostgreSQL
- Vercel
- YGOPRODeck API

## Variáveis de ambiente
